# Client Demo Guide

Open `client-demo/index.html` directly in Chrome/Edge. Use `SEC1001` / `Gate@123`.

Suggested presentation:
1. Show premium login and tablet responsiveness.
2. Open Control Room and explain alerts.
3. Create New IN Entry and load the demo crew pass.
4. Explain read-only QR fields, TT match, duplicate protection and safety workflow.
5. Submit and show the generated serial/status.
6. Open Today's Records and demonstrate search.

Clarify that the standalone demo stores data in the browser; the full project uses Express, PostgreSQL, Prisma and secured sessions.
