# Handover Checklist

- Source repository and release ZIP/checksum received
- Environment values transferred through approved secret channel
- Database owner, backup owner and restore procedure assigned
- Official QR/pass adapter owner assigned
- Safety SOP and destination master owner assigned
- User provisioning/deactivation process documented
- Web/API hostnames, certificates, CORS and cookie domain confirmed
- Monitoring and incident contacts confirmed
- Target tablet/scanner inventory tested
- CI build, migration, tests and security scans passed
- UAT and go-live approval signed
